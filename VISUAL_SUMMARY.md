## 📈 综合评分策略详解

### 评分公式

```
总分 = w₁×改向成本 + w₂×岸壁安全 + w₃×避让效果 + w₄×连续性

默认权重:
w₁ = 0.3  (改向成本)
w₂ = 0.3  (岸壁安全)
w₃ = 0.25 (避让效果)
w₄ = 0.15 (连续性)
```
