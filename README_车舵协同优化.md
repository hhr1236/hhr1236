# 车舵协同避让决策优化系统

## 简介

这是对原有船舶避让决策系统的重要升级，从**单一角度优化**扩展到**车舵协同优化**，实现了转向角度和速度档位的联合优化。

## 核心特性

### 🎯 多维决策空间
- **原系统**：仅优化转向角度 (5° - 35°)，31种方案
- **新系统**：优化 (角度 × 速度档位) 组合，93种方案

### ⚙️ 速度档位控制
```python
速度档位设置（修改 list_own_ship_initial[11]）：
- 前进三: 85/60 ≈ 1.417 m/s  # 正常航行
- 前进二: 70/60 ≈ 1.167 m/s  # 谨慎避让
- 前进一: 48/60 ≈ 0.800 m/s  # 紧急减速
```

### 📊 多目标优化
同时优化3个目标：
1. **DCPA** - 最近会遇距离（安全性）
2. **风险度** - 航道边界风险（合规性）
3. **避让时间** - 操作效率

## 应用场景

### 场景1：紧急避让（优先安全）
```python
weights = {'dcpa': 0.50, 'risk': 0.30, 'steps': 0.20}
# 结果：选择更大的DCPA，确保安全距离
```

### 场景2：平衡模式（均衡各项指标）
```python
weights = {'dcpa': 0.40, 'risk': 0.35, 'steps': 0.25}
# 结果：在安全、风险和效率之间取得平衡
```

### 场景3：快速避让（优先效率）
```python
weights = {'dcpa': 0.30, 'risk': 0.30, 'steps': 0.40}
# 结果：选择更快完成避让的方案，通常是前进三
```
