### 🚢 Ship Navigation LLM System (船舶智能航行知识系统)

An intelligent ship navigation knowledge management system using Large Language Models (LLM) to understand and query navigation rules from different water regions.

**Key Features:**
- 📚 Ingest navigation rule PDFs from different waters
- 🤖 LLM-powered understanding of navigation regulations
- 💬 Natural language Q&A about navigation precautions
- 🗺️ Guidance for nautical chart feature selection and modeling
- 🌊 Support for multiple water regions

**Technology Stack:** Python, LLM (OpenAI/Local), RAG (Retrieval-Augmented Generation), Vector Embeddings
