# 船舶智能航行知识系统 - 项目总结

## 项目概述

本项目实现了一个基于大语言模型(LLM)的船舶智能航行知识管理系统，满足以下需求：

1. ✅ 能够导入不同水域的通航规则PDF文档
2. ✅ 使用LLM理解和学习航行注意点
3. ✅ 通过自然语言查询特定水域的航行要求
4. ✅ 提供海图要素选择建议，辅助建模
5. ✅ 支持离线工作模式（无需API密钥）

## 系统架构

```
船舶智能航行知识系统
├── 文档处理层 (Document Processing)
│   ├── PDF处理器 - 提取PDF文本内容
│   ├── 文本处理器 - 处理纯文本文档
│   └── 文档分块 - 智能分割长文档
│
├── 知识存储层 (Knowledge Storage)
│   ├── 向量存储 - 存储文档嵌入向量
│   ├── 知识库 - 管理文档元数据
│   └── 相似度检索 - 查找相关文档
│
├── LLM交互层 (LLM Interface)
│   ├── 嵌入生成 - 创建文本向量表示
│   ├── 查询处理 - 理解用户问题
│   └── 回答生成 - 基于文档生成答案
│
└── 应用层 (Application Layer)
    ├── 命令行界面 - 交互式/单次查询
    ├── 系统工具 - 状态检查、数据管理
    └── 示例程序 - 完整工作流演示
```

## 核心功能

### 1. 文档导入 (Document Ingestion)

**功能**：
- 支持PDF和TXT格式
- 自动提取和分块文本
- 创建向量嵌入
- 持久化存储

**使用方法**：
```bash
# 创建示例数据
python main.py --create-examples

# 导入文档
python main.py --ingest data/navigation_rules
```

### 2. 智能问答 (Intelligent Q&A)

**功能**：
- 语义检索相关文档
- RAG增强生成
- 中文友好
- 离线工作模式

**使用方法**：
```bash
# 交互式查询
python main.py --interactive

# 单次查询
python main.py --query "渤海湾航行需要注意什么？"
```

### 3. 海图建模指导 (Chart Modeling)

**功能**：
- 提取海图要素
- 优先级排序
- 结构化建模
- GIS集成准备

**使用方法**：
```bash
cd examples
python nautical_chart_modeling.py
```

### 4. 系统管理 (System Management)

**功能**：
- 状态检查
- 数据清理
- 文档列表

**使用方法**：
```bash
# 检查系统状态
python utils/system_utils.py status

# 列出文档
python utils/system_utils.py list

# 清理数据
python utils/system_utils.py clean
```

## 技术实现

### 核心技术栈

1. **Python 3.x** - 主要开发语言
2. **NumPy** - 数值计算和向量操作
3. **PyPDF2/pdfplumber** - PDF文本提取（可选）
4. **OpenAI API** - LLM服务（可选）

### 关键算法

1. **文档分块 (Text Chunking)**
   - 固定大小分块（1000字符）
   - 重叠策略（200字符）
   - 保持上下文完整性

2. **向量嵌入 (Vector Embedding)**
   - OpenAI模式：text-embedding-ada-002
   - 离线模式：MD5哈希嵌入
   - 384维向量空间

3. **相似度检索 (Similarity Search)**
   - 余弦相似度计算
   - Top-K结果返回
   - 向量归一化

4. **RAG生成 (RAG Generation)**
   - 检索相关文档片段
   - 构建提示上下文
   - 生成专业回答

## 示例数据

系统包含三个水域的示例航行规则：

1. **渤海湾**
   - 基本规定和航行注意事项
   - 主航道规格和分道通航制
   - 禁航区域和指定锚地
   - 海图要素标注要求

2. **长江口**
   - 水域特点（咸淡水交汇）
   - VTS管制和通讯要求
   - 南北槽航道说明
   - 潮汐影响和避让规则

3. **珠江口**
   - 船舶定线制要求
   - 主要航道（虎门、蕉门、洪奇沥）
   - 台风季节注意事项
   - 保护区和限制区

## 使用场景

### 场景1：航行规划
研究人员查询特定水域的航行注意事项，获取详细的规则说明。

### 场景2：海图建模
基于LLM回答，提取关键海图要素（航道、锚地、禁航区等），指导GIS建模。

### 场景3：培训教学
学员通过问答方式学习不同水域的通航规则。

### 场景4：规则对比
比较不同水域的航行要求差异，研究通航规则特点。
